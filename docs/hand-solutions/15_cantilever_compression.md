# 15_cantilever_compression

Rightward horizontal forces are positive; N is positive in tension.

Horizontal reaction at the restrained support: 12 kN.

At each cut, N(x) = minus the sum of horizontal forces to its left.

- N(0, left) = 0 kN.
- N(0, right) = -12 kN.
- N(5, left) = -12 kN.
- N(5, right) = 0 kN.
